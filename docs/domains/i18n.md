# Internationalization

This page describes the two coordinated features that make a menu multilingual: enabling
languages for a restaurant, and translating menu entities with DeepL machine translation
and manual edits.

This page is partial. It states the purpose, the structure, and the key files, but does
not yet contain a full walkthrough.

## Status

Complete. The public menu serves locale-prefixed routes and emits hreflang alternates.

## Data model

- `restaurant_languages` and `restaurants.defaultLanguageCode`, both in
  `packages/db/src/schema/restaurants.ts`.
- `translations` (`packages/db/src/schema/translations.ts`) holds `entityType`, which is
  `dish`, `category`, `variant_group`, `variant_option`, or `ingredient`; `field`;
  `value`; `status`, which is `ok` or `pending_update`; and `source`, which is `machine`
  or `manual`.

## Backend

`apps/api/src/modules/admin-translations/admin-translations.router.ts` defines two
sub-routers. `languages` provides `catalog`, `list`, `add`, `setActive`, `remove`, and
`translateAll`. `translations` provides `list` and `update`. They are mounted in the root
router as `admin.languages` and `admin.translations`.

Machine translation is implemented in `deepl.service.ts`, with the helpers
`language-catalog.ts`, `translate-all.ts`, and `list-translations.ts`.

The repositories are `restaurant-languages.repository.ts`,
`admin-translations.repository.ts`, and `translations.repository.ts`. The model is
`packages/db/src/models/translation.ts`.

## Frontend

- Admin. The routes are `apps/admin/src/app/routes/_auth.languages.tsx`,
  `_auth.languages.index.tsx`, and `_auth.languages.$languageCode.tsx`. The feature
  directory is `apps/admin/src/features/languages/`.
- Public. Internationalization helpers are in `apps/web/src/lib/i18n/`, routes are
  locale-prefixed as `{-$locale}.*`, and hreflang links come from
  `apps/web/src/features/menu/seo/build-hreflang-alternates`.

## Key files

| Concern                                     | Path                                                                                                |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Languages and default language              | `packages/db/src/schema/restaurants.ts` (`restaurant_languages`)                                    |
| Translations schema                         | `packages/db/src/schema/translations.ts`                                                            |
| Admin router for languages and translations | `apps/api/src/modules/admin-translations/`                                                          |
| DeepL service                               | `apps/api/src/modules/admin-translations/deepl.service.ts`                                          |
| Repositories                                | `packages/db/src/repositories/{restaurant-languages,admin-translations,translations}.repository.ts` |
| Admin UI                                    | `apps/admin/src/features/languages/`, `apps/admin/src/app/routes/_auth.languages.*`                 |
| Public internationalization                 | `apps/web/src/lib/i18n/`                                                                            |

## Limitations

- `translations.status = pending_update` marks a machine-translated or source string that
  changed and may need to be translated again. Surface this state in the admin UI.
- DeepL is configured through the environment, using `DEEPL_API_URL` and an API key. Keep
  the key server-side.
