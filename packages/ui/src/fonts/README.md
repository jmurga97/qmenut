# QMenut web fonts

This directory contains the curated latin and latin-ext woff2 subset files used by the public web app. They are vendored from the matching @fontsource packages listed in the adjacent family CSS files. Geist and Geist Mono ship as single variable files (`*-variable.woff2`) taken from Vercel's `geist` package via the Ming design system. All included font files are distributed under the SIL Open Font License 1.1 (OFL-1.1).
